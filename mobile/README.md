# 手机远程

当前桌面产品**停放**：侧栏无远程入口，3180 不监听。下列步骤只在重新打开 `REMOTE_FEATURE_ENABLED` 之后才对用户成立。

中文 · 浏览器扫桌面 **远程** 弹窗里的二维码，打开的是 `mobile/web` 这套独立 SPA，不是官方四栏 `dsh web`。

## Web

1. 桌面打开远程，选局域网或 HTTPS 中继。
2. 系统相机 / 浏览器扫码。密钥只在 `#offer=`。
3. 3180（或中继）登录后返回本目录的 `index.html`。`/api/*` 和 WebSocket 仍转到本机 `127.0.0.1:3080`。
4. 开发时：`npm test` 会跑 `mobile/web/**/*.test.js`。

中继必须是 HTTPS。流量会经过中继运营方；这不是会话内容的端到端加密。

## Android

应用内扫码和原生页还没做。请先用系统浏览器打开配对链接。不要用 WebView 套官方 UI。
