# @deepseek-ai/dsh-client-ui-layout

English | [中文](README.zh.md)

Shell plugin: four-column AppFrame (drag handles and concession chain) plus the `ctx.layout` panel-geometry service; it registers into the runtime-owned `root` slot and declares `sidebar`, `conversation`, `details`, `surfaces`, `shell.overlay`, `shell.titlebar.trailing`, and `shell.terminalDrawer`. The sidebar resize boundary is an invisible hit strip, while the details and surfaces boundaries retain a floating pill; concession shrinks surfaces to its minimum, then details, then derived-closes surfaces, then details. A closed sidebar retains a 56px control rail; closed details and surfaces are width 0. In portrait below `PHONE_MAX` (768px) the sidebar and details tracks go to zero: conversation is full width, the sidebar is an overlay drawer, and details is a full-screen overlay; drag handles are omitted. Any frame below 1024px, and any `[data-phone]` frame, hide the titlebar trailing cluster so Session log, Git, and panel toggles do not overlay the session title; the slot stays mounted. When that cluster stays visible over a squeezed conversation column, AppFrame publishes `--dshd-titlebar-conversation-reserve` and a `full` / `cozy` / `compact` density so the header pads and labels collapse ([titlebar crowding](../../../.agents/notes/implemented/bug-fix/2026-08-17-titlebar-crowding-density.md)). Landscape keeps the sidebar in the grid and does not auto-collapse to the rail; landscape is device rotation (`screen.orientation.type`, then physical `screen.availWidth`/`availHeight` when that type is stale or `orientation.change` does not fire), not a keyboard-shrunk viewport. The package also seats the theme presenter: it consumes resolved `ctx.theme` snapshots and projects them onto the document (`html { color-scheme }` for native UA chrome, `body[data-ds-dark-theme]` from the active color scheme, the theme's alias tokens as inline variables on body, and one owned `<meta name="theme-color">` whose content follows the computed body background). Measuring after palette and token application keeps the rendered background as the single color authority; disposing the presenter removes its metadata node with its other global writes.

AppFrame always mounts the conversation, details, and surfaces columns plus the conversation-only terminal drawer; a connected Session renders through `SessionProvider`. The layout store starts the sidebar at its default width and details closed. Surfaces width and terminal-drawer height persist last-open sizes (and whether they were open) in `localStorage` key `dshd.layout.panels`; sidebar and details stay session-transient. Hero and other unselected states also derive a zero rendered details width without changing that stored preference. AppFrame retains the last non-blank Session id across those states: the first Session remains closed, an explicit details action opens the contract default width, returning to the same Session restores its unchanged width, and selecting a different Session closes details before paint. Titlebar toggles write only surfaces and the terminal drawer; they do not open or close details. AppFrame's first grid row is a shared titlebar band: the conversation header sizes that row through subgrid, the band covers details only, and surfaces spans every row to the window top. When surfaces is open the trailing cluster occupies columns 2–3 so it does not overlay the right panel; window controls clear the surfaces tab bar via `--dshd-wco-controls` on that tab bar. When surfaces is closed the cluster spans to the right edge, inset from the window controls. The trailing cluster is `-webkit-app-region: no-drag`. Conversation caption rows own drag; the Electron inject script paints only the window-control plate. Details starts on the body row below so its hairline does not run through Session log, Git, or window controls. The conversation owner share is empty, while the sidebar owner share contains only `collapsed` and `width`; registrants obtain business data from standard hooks and actions from their own inject faces.

The `/client` exports are the plugin body (`apply`/`inject`), `LayoutController`, and the owner-share interfaces. AppFrame, the panel store, and the concession solver remain package-internal.

## Model Experience

None, as the layout shell manages browser viewing state; nothing here reaches a model request.

#### KV Cache effect

None; this package neither assembles nor sends a provider request.

## Known Limitations and Deferred Work

- **Sidebar and details stay session-transient** — reload restores the sidebar default and details closed; switching between distinct Session ids also closes details and forgets its dragged width, while unselected surfaces render details at zero width without modifying geometry. Surfaces width and the terminal drawer persist last-open sizes.
- **Concession-chain auto-close derives a zero width without touching the preferred width** — the panel restores itself when the window widens; consumers must not read the stored details width as the rendered truth.
- **No scroll anchoring during squeeze reflow** — layout changes may move the reader's viewport.
