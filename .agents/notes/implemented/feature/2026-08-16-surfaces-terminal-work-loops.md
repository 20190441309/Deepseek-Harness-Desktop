# Agent Note: Right-panel and terminal work loops

Status: implemented

English | [中文](2026-08-16-surfaces-terminal-work-loops.zh.md)

## Problem

The desktop surfaces column and conversation terminal drawer shipped a five-card shell and PTY split, then stopped at thin viewers. Files could not search or save. Browser was a naked URL box. Diff's empty card lit up for any cwd and reused server-session copy. Terminal selection could not enter the composer. Empty-state cards are not a finished column.

## Decision

Keep the dsh slot/store composition and `--dsw-alias-*` chrome. Implement the work loops this desktop can own:

- Files: name search (depth 8 / 200 dirs; the panel reports when the budget stops the walk), utf8 edit/save through `shell:write-file` (workspace-authority, 512 KiB cap). Refresh reloads the root listing; while a search is active it re-walks that search so nested matches are not dropped. Mention is a row `@` into the composer and is omitted without a session id; the context menu copies relative or absolute path. A failed write keeps the editor and the unsaved buffer. Closing a dirty `surfaces.file` tab confirms (Keep / Discard / Save); `FilePreview` reports dirty via `onDirtyChange` even when cwd is briefly missing, hydrates from `readBuffer` before paint, and does not show the editor until the first read settles. Occupant React keys and dirty callbacks are session-scoped so two sessions with the same path keep separate drafts. In-memory buffers survive session switches until the tab closes; a dirty draft is kept when disk bytes change under it, and a failed reread does not wipe it. Save (toolbar, Ctrl/Cmd+S, and close-dialog) writes while the tab is active, cwd exists, and the draft is dirty, including when the last reread failed or returned truncated or binary bytes. A dirty draft stays in the editor (Markdown Source included) in those cases and when cwd is missing; Save stays disabled until cwd returns. A successful write clears truncated/binary so the editor remains. Dirty drafts persist in the surfaces localStorage bucket across reload and quit (`pagehide` / `beforeunload` flush, canceling a pending debounce so Discard cannot be overwritten). Activating a file tab rereads disk under the draft. Save rereads first and refuses once when disk diverged from both the remembered baseline and the draft (`error.changed`).
- Browser: back / forward / reload / DevTools / system-browser (URL bar, even before a guest) / discovered loopback ports (rescanned while the occupant is mounted); chrome is icon Back/Forward/Reload, an `Input` that submits on Enter, a system-browser icon, and a More menu for DevTools. Guest `did-navigate` / `did-navigate-in-page` emit `shell:preview-state-change` so the URL bar and back/forward follow in-guest navigation. Document navigation stays on loopback; CDN subresources are allowed. Open occupants stay mounted across surface tab switches (`active` hides the guest via `previewHide`; `occluded` also hides it while surface menus or the unsaved-file dialog overlap the native hit-test area; the More menu hides it while open; closing the tab calls `previewClose`). Terminal `dshd-open-surface` plus `dshd-pending-preview-url` opens the guest when the occupant mounts later (including blank session keys). Each client package repeats those two strings; slot rules forbid a shared value export.
- Diff: `gitStatus` empty-card gate; Working tree vs Branch (`gitDiff(cwd, { baseRef })` three-dot range, non-zero exit returns null); a valid repo with a failed diff shows the load error, not the non-repo card. Working-tree hunks are `git diff HEAD` (staged and unstaged on the same file). Porcelain Stage / Unstage / Discard stay on the file list when an op fails (`opError` banner); untracked (`??`) discard runs `git clean -f` (`-fd` for directories). Collapse all / Expand all. The branch Menu searches every listed ref. Branch scope hides Stage / Unstage / Discard. Split view, ignore-whitespace, and word-wrap toggles stay out.
- Terminal: selection Copy / Add to chat (fenced `terminal` draft via `ctx.get('conversation')`; the action is disabled without a session id); ⌘/Ctrl-click and selection Open for http(s) and workspace paths; loopback http(s) opens Browser and other http(s) calls `window.shell.openExternal`; maximize restores the last **conversation drawer** height (the `surfaces.terminal` occupant has no separate maximize).
- Layout: `dshd.layout.panels` persists last-open surfaces width and terminal-drawer height, including whether they were open.

GPU terminal embedding, worktree environments, checkpoint turn-diff, review-comment pick, preferred-editor Open-in picker, drag-to-composer, and PiP/recording stay out: this harness has no equivalent session metadata, and shipping a half-stack would lie. Terminal links rejoin wrapped xterm rows and strip `:line:column` because FilePreview has no jump-to-line. Agents rows use the session-list snapshot (running/inactive, mode, jobs); job lifecycle status uses locale copy; jobs are read-only; there is no token counter or workflow-script tree on that snapshot.

## Alternatives considered

**Ship the five cards and call the column done.** Rejected: the value is the loop (search, save, navigate, select-into-chat), not the card grid.

**Paste Tailwind GPU-terminal occupants.** Rejected: design-language rule 15 and the slot/four-share contract.

**Fake turn-diff from conversation events.** Rejected: no durable checkpoint range exists; a fake Latest turn would be a second downgrade.

**Treat Diff chrome (split / wrap / ignore-whitespace) as required for the work loop.** Rejected: those are rendering toggles; the loop is search, save, navigate, and select-into-chat. Split remains a Diff README limitation.

## Consequences

`workspace-fs.writeFile`, `preview.back/forward/reload/state/openDevTools/discover` plus `shell:preview-state-change`, and `gitDiff(..., { baseRef })` are the desktop IPC. Privileged BrowserView / BrowserWindow navigation uses hostname-parsed loopback checks (`local-url.js`), boot `file:` is pinned to packaged `boot.html`, marketplace `file:` is pinned to packaged `marketplace/index.html`, `showHarness` rejects non-loopback base URLs and rewrites `0.0.0.0`, denied navigations only `openExternal` http(s), and both `will-navigate` and `will-redirect` are guarded. Client packages consume them through existing `window.shell` injects. Terminal selection writes a fenced draft, not a composer chip. File opens from the terminal go through `workspaces.openPath` (desktop intercepts into Files) and drop `:line:column` because the file surface has no jump-to-line. Work loops (search, save, guest URL, Stage/Discard, loopback vs system browser) are in this note; Diff split / wrap / ignore-whitespace stay out.
